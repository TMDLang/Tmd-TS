AI Co-Composing Patterns

                
Whether generating inside this Web Studio or working with external AI tools, these 5 prompt patterns help you arrange and compose effectively:


                

                  
                  

                    
1. Lead-to-Arrangement

                    
You compose the vocal melody in TMD; prompt the AI to generate supporting tracks (acoustic guitar chords, walking bass, and drum groove).

                    
Prompt Example: 'Here is my vocal melody in TMD. Please arrange accompaniment: add a CHORD track with acoustic guitar chords, a Bass track with root/passing notes, and a Drums track entering at measure 2 with @|+2|.'

                  


                  
                  

                    
2. Motif Continuation & Phrasing

                    
Provide a 2 to 4-measure melodic hook; prompt the AI to develop it into a full 8-measure section using antecedent-consequent question-and-answer phrasing.

                    
Prompt Example: 'Here is a 2-bar motif: 1 2 3 5 | 6 5 3 -. Please develop this into a complete 8-bar section using classical question-and-answer phrasing, resolving to the tonic on bar 8.'

                  


                  
                  

                    
3. Re-Harmonization & Chord Exploration

                    
Because chords in TMD are first-class tokens ([Cmaj7], [Am7], [1], [6m]), you can effortlessly ask the AI to propose diverse harmonic flavors.

                    
Prompt Example: 'Propose two different TMD chord arrangements for this melody: 1. Standard pop 1-5-6-4; 2. Neo-Soul / Jazz progression with secondary dominants and modal interchange.'

                  


                  
                  

                    
4. Textural Layering & Arrangement Build-Up

                    
Use TMD's track offset syntax @|0|, @|+4| and pickup measures @|-1| to orchestrate gradual instrument entry and dynamic builds.

                    
Prompt Example: 'Verse 1: Acoustic Guitar only; enter Bass at measure 4; add a Drum fill-in 1 bar before Chorus with @|-1|, followed by full-band tutti in Chorus.'

                  


                  
                  

                    
5. Macro Song Structuring & Modulations

                    
After authoring individual song sections, have the AI plan the overarching playback sequence and half-step key changes in ->.

                    
Prompt Example: 'I have defined intro, verse, chorus, and bridge. Please design a complete -> playback flow with a half-step key modulation {?+1} for the final chorus.'

TMD Quick Reference & Philosophy

          
        

        

          
TMD (Timebase Mark Down) was designed by composer and producer aguai (阿怪). Unlike black-box audio generation (like Suno), TMD gives artists full creative agency over exact notes, chords, and arrangements. Built for creative thinking rather than sheet music printing, it is the ultimate pair-composing DSL for the AI era. Let's write music together!

          
::SCORE::
** Song Title **
!= 120              /* Tempo BPM */
?= C                /* Key signature */
<4/4>               /* Time signature */

/* Section:Instrument@|MeasureOffset|{ ... } */
intro:Piano@|0|{
  <2*>              /* 2 beats per unit */
  |[1] - | [6m] - |
}

verse:Lead@|0|{
  <4*>              /* 4 beats per unit */
  | 1 2 3 1 | 5 - 3 - |
}

/* Playback order and modulation */
-> intro -> verse -> {?+1} -> verse ->#

          
    
            
  • 1–7: Jianpu scale degrees; ^: Octave up; _: Octave down.
    • 
            
  • 1', 4': Sharp semitone; 2,, 7,: Flat semitone. Stackable with octaves like 1'^ or 7,_.
    • 
            
  • [1], [6m], [Cmaj7]: Chord symbols.
    • 
            
  • (1 2 3)%(--): Tuplets across unit groups (e.g. triplets).
    • 
            
  • (1 2)%(-), (1 2 3)%(-): Tuplet note subdivisions (evenly dividing notes within the duration defined in %(-)).
    • 
            
  • {!= 140}, {?+2}: Dynamic tempo and key directives.
    •

              💡 演算法原理與對位法設計 (Counterpoint Architecture)
            
            

              
1. 和聲地基 (Ground Bass)：自然調式採帕海貝爾 Romanesca 進行 (I-V-vi-iii-IV-I-IV-V)；五聲調式採宮/羽調循環低音，天生避開小二度與三全音衝突。

              
2. 強拍和弦音咬度 (Chord Gravity)：小節強拍（第 1、3 拍）100% 鎖定和弦內音 (Root, 3rd, 5th)，確保複音聲部縱向縱使交錯追逐仍穩固協和。

              
3. 級進歌唱偏好與補償 (Voice Leading)：選音 ~75% 走相鄰二度級進；若出現大於二度之大跳，次個音 80% 強制反向級進解決 (Gap-Fill)，保持旋律如呼吸般自然。

              
4. 對稱與變奏 (Forms)：支援輪唱 (Staggered)、螃蟹逆行 (Crab)、倒影 (Mirror)、雙倒影逆行桌子卡農 (Table)，並涵蓋 Cantabile、Lilt、Flourish 等 5 種巴洛克變奏風格。
